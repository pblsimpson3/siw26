Project Saugus Iron Works 2026

I'm Robert Simpson, an instructional designer and educator. Project SIW26 has modernized and resurrected the mid-2000s Saugus Iron Works Great Adventure Project-Based Unit (PBU). By harnessing the power of generative AI tools such as Claude.ai and Gemini Pro the web code has been updated and replacement resource websites have been added. All updated files are shared in a GitHub respository. Additionally the project uses Google Analytics tags to monitor page use statistics such as views, external link resource use and interactive elements.

SIW26 Development Goals

  • W3C Compliant
  • Fully Accessible
  • Maintainable
  • Performance-optimized
  • Responsive design (mobile friendly)
  • Preserve 2000s aesthetic & instructional design
